作品集 · 使用说明
==================

一、怎么开始
1. 双击「作品集.exe」
2. 第一次会弹出设置窗口：填两个密钥（对话 + 检索），点「测试连接」，看到三个绿勾再点「保存」
3. 以后双击就能直接用

不需要安装 Python、Docker，也不用改任何配置文件。

二、密钥从哪来
· DeepSeek（对话）：https://platform.deepseek.com  →  API keys  →  新建
· 硅基流动（检索）：https://cloud.siliconflow.cn  →  API 密钥（模型用默认的 BAAI/bge-m3）
· 视觉模型（可选）：给图片自动写描述，不填也能用，只是图片不会自动描述

密钥只保存在这台电脑上：%LOCALAPPDATA%\作品集\设置.json

三、加作品
点「+ 新增」，把文件拖进去就能加：图片、PDF、Word、Excel、PPT、代码、视频都行。
标题可以留空（自动用文件名）。图片会自动生成一段描述，视频只记录元数据。
一次可以拖多个文件，每个文件会单独成为一条作品。

四、数据存在哪、怎么备份
%LOCALAPPDATA%\作品集
    作品集.db      作品和对话记录
    向量库\        检索用的向量（删掉也能靠作品正文重建）
    作品文件\      你上传的原件

整个「作品集」文件夹复制走就是完整备份；换电脑时把它复制到新电脑的同一位置即可。

五、怎么退出
设置 → 退出程序。直接关窗口只是关掉界面，后台还在跑（再双击会直接连回刚才那个）。
运行日志在 %LOCALAPPDATA%\作品集\运行日志.txt，出问题时把它发过来就能定位。

六、常见问题
· 双击没反应：看任务管理器里有没有「作品集」进程，再看运行日志最后几行
· 提问提示「还没有填…密钥」：设置里填上再保存
· 上传图片报错：视觉密钥没填或额度用完了；不影响其他功能
· 杀毒软件报毒：PyInstaller 打包的 exe 常被误报，加入白名单即可
· 换了电脑/改了路径：把「作品集」文件夹一起复制过去，数据不会丢
