作品集 · 使用说明
==================

一、怎么开始
1. 确保 Docker Desktop 已安装并启动（第一次双击时也会尝试自动启动）
2. 双击「作品集.exe」
3. 客户端会打开 Docker 正式版；桌面端、手机端和浏览器共用同一套数据

这是 Docker 正式版的桌面入口，不是另一套独立数据库。

二、配置密钥
在仓库根目录的 `.env` 中填写 DeepSeek、嵌入模型和视觉模型密钥。密钥由 Docker backend 读取；不要把 `.env` 分享或提交到 Git。

三、加项目、加素材
1. 点「+ 新增项目」，标题必填；简介、标签、封面都可以不填
2. 进项目后点「+ 添加素材」，把文件拖进去就行：图片、视频、音频、PDF、Word、Excel、PPT、代码、文本都行
3. 类型按文件扩展名自动判定（图片/视频/音频/文本/代码/文档），不用你选
4. 一次可以拖多个文件，每个文件单独成为一件素材；音频不转写，只保存你填的备注
5. 一件素材可以同时挂在多个项目下；删项目默认不删素材（要一起删可以在删除时选）
6. 素材建好之后，卡片上有「编辑」，可以改标题、正文/描述和标签
7. 编辑时还能「替换文件」：片子重剪、文稿改第二版，直接换掉文件即可，
   正文会按新文件重新解析，标题和所属项目保持不变（旧文件副本会被清掉）

四、数据存在哪、怎么备份
Docker 命名卷保存 PostgreSQL、Chroma 和上传媒体。备份前先停止 backend/nginx 写入，再运行仓库里的 `scripts/backup.ps1`；同时保留数据库导出和媒体文件，并核对 manifest 哈希。

不要复制或删除 exe 的本地 SQLite 文件来同步 Docker 数据，两者不再是两套数据库。

五、怎么退出
设置 → 退出程序。直接关窗口只是关掉界面，后台还在跑（再双击会直接连回刚才那个）。
运行日志在 %LOCALAPPDATA%\作品集\运行日志.txt，出问题时把它发过来就能定位。

六、常见问题
· 双击没反应：看任务管理器里有没有「作品集」进程，再看运行日志最后几行
· 提问提示「还没有填…密钥」：设置里填上再保存
· 上传图片报错：视觉密钥没填或额度用完了；不影响其他功能
· 杀毒软件报毒：PyInstaller 打包的 exe 常被误报，加入白名单即可
· 换了电脑/改了路径：把「作品集」文件夹一起复制过去，数据不会丢
